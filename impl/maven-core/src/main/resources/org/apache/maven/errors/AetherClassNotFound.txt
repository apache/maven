A plugin uses the old Sonatype Aether API (org.sonatype.aether.*), which Maven
replaced with Eclipse Aether / Maven Resolver many releases ago.

Plugins that still depend on org/sonatype/aether classes cannot run on modern
Maven versions. Upgrade the plugin to a version compatible with the Maven
version you use; the plugin index at https://maven.apache.org/plugins/index.html
lists the current releases of the common plugins.
