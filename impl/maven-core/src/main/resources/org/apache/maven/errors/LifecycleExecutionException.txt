A lifecycle phase could not complete because one of its bound plugin goals
failed, or because Maven could not build the project model (for example when a
parent POM or one of its modules cannot be read).

Look at the "Caused by" entries of the stack trace (re-run with -e to see the
full trace) to find the underlying failure, then fix that root cause: plugin
execution errors are usually reported against the exact goal and project that
failed.
