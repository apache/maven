Maven could not connect to a remote host.

This often happens when Java prefers IPv6 while the host or the network only
supports IPv4. If the stack trace shows a "Connection refused" while establishing
a loopback connection, force Java to use IPv4 with:

  -Djava.net.preferIPv4Stack=true

Add this option to MAVEN_OPTS to apply it to all Maven commands.
