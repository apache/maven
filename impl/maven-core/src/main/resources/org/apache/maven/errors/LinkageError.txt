A plugin or extension could not be loaded because of incompatible or conflicting
classes on its class path.

This usually happens when a plugin (or one of its dependencies) was built against
a different version of a library than the one resolved at build time, or when the
plugin is not compatible with the Maven version in use. Check the versions of the
plugin and of the dependencies it declares, and align them with the ones the
plugin requires. Upgrading the plugin, or explicitly aligning the conflicting
dependency versions, typically fixes the problem.
