Maven could not load a goal from its plugin class path.

Possible causes:
- the plugin JAR or POM (or one of its dependencies) was corrupted while being
  downloaded; delete the affected files from your local repository (usually
  ~/.m2/repository) and let Maven re-download them
- custom plugin dependencies declared in your POM are not compatible with the
  plugin; align their versions with the ones the plugin natively uses
- the plugin was not assembled properly by its creator; report the problem to
  the plugin maintainer
