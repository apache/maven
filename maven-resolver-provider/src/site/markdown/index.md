# Maven Artifact Resolver Provider

Maven Artifact Resolver Provider is a [Maven Artifact Resolver](/resolver/) extension to support Maven POMs and local+remote repositories.

Main component is `MavenRepositorySystemUtils` ([javadoc](./apidocs/org/apache/maven/repository/internal/MavenRepositorySystemUtils.html), [source](./xref/org/apache/maven/repository/internal/MavenRepositorySystemUtils.html)).
